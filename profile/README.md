# Astrolabe

**An unofficial wiki, toolkit and mod loader for Melvor Idle 2.**

[Wiki](https://astrolabe-melvor.github.io/) · [Tools](https://github.com/Astrolabe-Melvor/tools) · [Loader](https://github.com/Astrolabe-Melvor/loader)

</div>

## What's here

| Project | What it does |
|---|---|
| [Astrolabe Wiki](https://astrolabe-melvor.github.io/) | Every skill, item, monster, quest and pet, with rates worked out from the game's data. Planners for any item or level, Astrology node order, and progression guides. |
| [Astrolabe Tools](https://github.com/Astrolabe-Melvor/tools) | Runs on your PC and reads your own save: best money and XP for your levels, gear you're missing, what to upgrade next. |
| [Astrolabe Loader](https://github.com/Astrolabe-Melvor/loader) | Loads C# mods into the game, with windows drawn in the game's own style and rebindable keys. |

Built for game version 0.11.6-alpha.1. The game is in alpha, so updates can change numbers before the wiki catches up.

## Not official

Astrolabe is a fan project. It isn't affiliated with Games by Malcs or Jagex, and it contains none of the game's files. Melvor Idle 2 names and artwork belong to their owners.
